\# Godot Beginner Tutorial – World Building



Welcome! 👋



This repository contains the project files for my Godot beginner tutorial.



The goal of this project is to provide a simple starting point for anyone who is new to Godot and wants to learn how to build a small 3D world.

\## 🚀 Getting Started



1\. Download the latest project ZIP using the link above.

2\. Open the \*\*Godot Online Editor\*\*.

3\. Upload the downloaded project.

4\. Open the project and start exploring.

5\. Follow along with the video tutorial.



I've tried to keep the project as simple as possible, making it suitable for beginners who are just getting started with Godot.



\---



\## 🛠️ Requirements



\- A modern web browser

\- Internet connection



You don't need any previous Godot experience to follow the tutorial.
